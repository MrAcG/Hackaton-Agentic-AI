# Two-minute one-slide poster outline (horizontal)

Build in **Canva** (non-AI mode) or similar. One horizontal slide; short sentences; strong visual of the VPN flow. Use a portal screenshot as the anchor — not only abstract gradients.

## Must-cover blocks

1. **Problem**  
   Employees wait; L1 repeats VPN / access / policy tickets.

2. **Competitors**  
   ITSM queues alone · single chatbots · brittle RPA — we add specialist agents + HITL.

3. **Target market**  
   Enterprise IT / shared-services ops evaluating agentic L1 assist.

4. **How it works** (center visual)  
   Ticket → Triage orchestrator → Specialist team → Chat + KB/tools → Resolve / Escalate  
   Optional mini-screenshots of portal Pending → Resolved.

5. **Evaluation & responsible AI**  
   Agent tests · API e2e scenarios · escalate when unsure · team-scoped KB · no real credentials.

6. **Team & links**  
   *(Add team name + repository URL / QR as required by the event.)*

7. **Sources / acknowledgement**  
   LangGraph · FastAPI · React · course / hackathon resources as required.

## Layout tip
Left: problem + market. Center: flow visual. Right: uniqueness + eval + QR/repo. Keep under ~80 words of body text.
