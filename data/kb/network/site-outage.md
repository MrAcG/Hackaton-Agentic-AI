# Office-wide network outage

## Symptoms
- Many users at one site report no network at the same time
- Core services unreachable from every device

## Checks
- Check site status for an open network incident
- Ping the core switch for the site

## Resolution
Not fixable by the user. Link the ticket to the open incident, tell the user it is a known
outage, and escalate to Network L2 / the incident owner.
