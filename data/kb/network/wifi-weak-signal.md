# Slow or unstable Wi-Fi in the office

## Symptoms
- Internet or apps are slow, video calls freeze
- Wi-Fi drops or disconnects intermittently
- High latency or packet loss

## Checks
- Check Wi-Fi signal strength (RSSI) and band for the device
- Ping the default gateway to measure latency and packet loss

## Resolution
Signal weaker than -75 dBm causes packet loss. Ask the user to move closer to an access point,
switch to the 5 GHz network "Corp-5G", or plug into ethernet.
If signal is strong but loss persists, escalate to Network L2 for access-point checks.
