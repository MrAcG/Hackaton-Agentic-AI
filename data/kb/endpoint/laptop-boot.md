# Laptop will not boot or is extremely slow

## Symptoms
- No power / black screen
- Stuck on logo
- Very slow after login

## Resolution
1. Confirm the charger LED and try another outlet/charger if available.
2. Hold power 10 seconds for a hard reset, then boot again.
3. If it boots: check Disk / Memory in Task Manager and note recent updates.
4. Persistent hardware faults are escalated to Endpoint / Desktop Support for imaging or replacement.
