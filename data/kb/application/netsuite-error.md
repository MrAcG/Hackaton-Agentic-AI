# NetSuite or business app error

## Symptoms
- Save / submit fails
- Permission or record lock errors
- Unexpected blank forms after an update

## Resolution
1. Note the exact error code and the record type you were editing.
2. Retry after a hard refresh; clear browser cache if the UI looks stuck.
3. Confirm coworkers are not seeing the same error (shared outage vs. personal role).
4. Escalate to Application Support with the NetSuite role, record id, and timestamp.
